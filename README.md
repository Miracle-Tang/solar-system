## ✨ 特性

### 画面
- **八大行星 + 冥王星**：受光面径向渐变（朝阳亮/背阳暗）、开普勒式轨道速度（内快外慢）、运动拖尾弧；**表面纹理随自转流动**（地球大陆漂移、金星逆向自转、火星极冠、海王星大暗斑）
- **2.5D 斜视角**：一键在「俯视圆盘 ↔ 斜视立体」间平滑过渡；各轨道按**真实近日点经度**取向错落，深度感质变
- **卫星系统**：地球的月球 + 木星四颗伽利略卫星（伊奥 / 欧罗巴 / 盖尼米德 / 卡里斯托）；天王星以 98°「躺倒」姿态携竖环
- **细节天体**：土星三层环（前后遮挡）、木星条纹与大红斑、火星—木星间 760 颗小行星带、海王星外柯伊伯带（520 颗）
- **彗星**：焦点椭圆轨道（dθ/dt ∝ 1/r²，近日点明显加速），越接近太阳尾巴喷得越旺，尾巴永远背向太阳；**掠过近日点触发闪光彩蛋**
- **太阳**：多层脉动日冕、循环生灭的耀斑日珥、持续吹出的太阳风粒子流
- **深空背景**：三层视差星空 + 银河尘埃带

### 交互
- **点击任意天体**：镜头平滑飞行并持续跟随（金色目标锁定环、长距离曲速速度线），左下弹出档案卡
- **导航条 / `←` `→`**：太阳 → 行星 → 彗星共 11 个目标一键/循环切换，每个天体一个音高，切换如弹音阶；**悬停导航按钮，画布内对应天体同步高亮**（轨道点亮 + 名称标签 + 虚线光环）
- **滚轮 / `+` `−` / 双指捏合** 缩放（0.25×–10×）、拖拽平移（拖拽/捏合时界面自动淡出，沉浸观星）
- **时间系统**：模拟日期显示（与地球公转同步，**点击日期回到今天**）、`+1年 / +10年` 时间跳跃、`Space` 暂停、0–10× 流速
- **2.5D 切换**：面板按钮或 `V` 键
- **悬停**：名称标签 + 虚线光环 + 所在轨道高亮
- **设置持久化**：音效 / 轨道 / 标签 / 帧率 / 视角 / 速度自动记忆（localStorage）；**切到后台自动静音**；尊重系统「减弱动态效果」设置（自动关闭曲速线）
- **手机端**：控制面板单行横滑，隐藏调试性控件，信息卡自动避让底部停靠区

### 音效
- 全部由 **Web Audio 实时合成**（零音频素材）：深空氛围嗡鸣垫、飞行 whoosh、目标音阶 blip

## 🛠 技术实现要点

- **纯 Canvas 2D**，无任何框架/库，全部代码在一个 `index.html` 里（约 1400 行，含详细中文注释）
- **坐标系统**：世界平面 → 2.5D 投影（y 轴按倾角压缩，平滑过渡）→ 屏幕；`w2s` / `s2w` 双向变换，滚轮/捏合以手势中心为锚
- **开普勒感**：行星角速度 ∝ r^-1.5；彗星按面积速率近似（dθ/dt ∝ 1/r²）
- **特效系统**：统一 `fx` 队列驱动锁定环 / 近日点闪光；镜头速度映射曲速线强度；放大场景下粒子类元素自动收敛
- **性能**：星空分层预渲染离屏画布、粒子上限受控、devicePixelRatio 上限 2×，60fps
- **音频**：AudioContext 全合成——失谐正弦叠加氛围垫、噪声缓冲 + 带通滤波 whoosh
